# Frontal Penguin Icon

Generated with the built-in image tool. Model version is not exposed.

- `source.png`: original generated artwork.
- iOS exports live in `../../ios/Runner/Assets.xcassets/AppIcon.appiconset/`, including the opaque 1024 x 1024 marketing image. All 19 manifest slots are generated from `source.png` at their declared sizes.

Installed through the existing Runner AppIcon asset catalog. This is flattened artwork with baked shading, not an adaptive Liquid Glass `.icon` package. Native system materials require separate clean layers and Icon Composer authoring. The system applies the outer corner mask.
